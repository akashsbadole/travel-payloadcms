## 💼 Business Model

### Revenue Streams
1. **Agent Commission**: 2% on every booking
2. **Customer Commission**: 1% on every booking
3. **Total Platform Commission**: 3% per booking
4. **Premium Listings**: Featured agent profiles
5. **Advertising**: Sponsored packages
6. **Subscription**: Premium agent plans

### Value Proposition
- **For Travelers**: Best prices, expert curation, hassle-free booking
- **For Agents**: Access to customers, easy quote management, timely payouts
- **For Platform**: Scalable marketplace, recurring revenue, network effects
